# Task: Create different variables, then add values and write them out!

Example variable types: 
- Create a string,
- an integer, and 
- a flag variable.
## What commands do you need to learn and use?
- `WRITE`, `DATA`, `=` (Assigning operator).

> **Hint**: If you get stuck, use ABAP Keyword Documentation (press `F1`) on the command!

<details>
<summary>Solution for String type </summary>

```abap
DATA string TYPE string.
string = 'Hello World!'.
WRITE string.
```
</details>

<details>
<summary>Solution for Integer type </summary>

```abap
NEW LINE. " Just to separate them.
DATA integer TYPE i.
integer = 5.
WRITE 'This is an integer: '.
WRITE integer.
```
</details>

<details>
<summary>Solution for Flag type</summary>

```abap
NEW LINE. " Just to separate them.
DATA flag TYPE flag. " it can be true or false
flag = abap_true. " or 'X'
WRITE: 'This can be true or false: ', flag. "You can merge WRITE commands
```
</details>
